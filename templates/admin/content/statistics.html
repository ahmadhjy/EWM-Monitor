One-time Google setup
  1. Verify elliottwavemonitor.com as a Domain property in Google Search Console using Google's DNS TXT record.
  2. Enable the Search Console API in a Google Cloud project and create a service account.
  3. Add its email to the Search Console property as a Restricted user (read-only access).
  4. Have the administrator install its JSON key in a private server file and configure SEARCH_CONSOLE_CREDENTIALS. Never paste private keys into chat, public forms, or the media library.
  5. Use property {{ google.property }}. Submit the website sitemap in Search Console.

Designed for privacy

Built-in analytics adds no tracking JavaScript or cookies. It stores daily aggregate counts, paths, referrer domains, edition, device category and approximate country—not visitor IPs, identifiers, full user agents or query strings. Staff visits, known bots, background archive loads and Do Not Track / Global Privacy Control requests are excluded. Bot filtering is approximate. Aggregates are retained for 180 days; normal server access logs are separate.
