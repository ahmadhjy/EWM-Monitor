# Arabic keyword targeting

The Arabic market pages target instrument-specific analysis and forecast intent:

- EUR/USD: تحليل اليورو دولار اليوم; توقعات اليورو دولار; توقعات اليورو مقابل الدولار
- Gold: تحليل الذهب اليوم; توقعات أسعار الذهب
- Oil: تحليل النفط اليوم; توقعات النفط الخام
- Bitcoin: تحليل البيتكوين اليوم; توقعات البيتكوين

These phrases were selected from current Arabic search results and actual market-page terminology, not from a measured keyword-volume dataset. Exact search-volume rankings need an authenticated Keyword Planner, Ahrefs, or Semrush export and a specified target country. No monthly search counts are claimed.

Keep publication dates visible on historical analyses. Do not change dates to make older forecasts appear new. Editors can set each Arabic focus keyword, SEO title, description, and social preview in the English admin.

English articles without Arabic titles and bodies have only English routes and sitemap entries. Arabic search, feeds, home, category, and related-article listings filter them out.

Reference examples:
- https://www.arabictrader.com/ar/analysis
- https://ar.tradingview.com/symbols/EURUSD/ideas/

The public-IP preview is intentionally noindex until domain cutover. After approval: set SITE_URL to the final domain, enable SITE_INDEXING_ENABLED, remove the Nginx preview noindex header, verify canonical/hreflang/sitemap URLs, and submit the sitemap to Search Console.
